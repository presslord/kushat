# Меню на день 🍳 (PWA v2)

Планировщик рациона для набора веса на двоих: календарь + ручная раскладка блюд по приёмам пищи.

## Экраны
- **📅 Календарь** — месяц с цветными точками: 🟢 день полностью собран, 🟡 выбрано не всё, 💖 отмеченный удачный день. Тап по дню → редактор.
- **День** — 5 слотов (завтрак, перекус 1, обед, перекус 2, ужин). Тап по слоту → шторка с вариантами из банка. Кнопка 🎲 дописывает только пустые слоты (ротация: не повторяет блюда последних 3 дней).
- **📖 Банк** — все варианты с рецептами и лайфхаками.

## Установка как приложения (PWA)
1. Раздать файлы по HTTPS (достаточно бесплатного хостинга):
   - **Netlify Drop**: перетащить папку `food-day-app` на https://app.netlify.com/drop
   - или GitHub Pages / Vercel.
2. Открыть ссылку на телефоне:
   - **Android (Chrome)**: появится баннер «Установить» внутри приложения (или меню ⋮ → «Установить приложение»). Иконка появится на рабочем столе, запускается без адресной строки, работает офлайн.
   - **iPhone (Safari)**: Поделиться → «На экран Домой».
3. Все данные (меню по дням) хранятся локально в браузере телефона (localStorage), интернет после установки не нужен.

## Запуск без сервера
Просто открыть `index.html` двойным кликом — календарь и выбор блюд работают (без иконки установки).

## Локальный сервер
```bash
python3 -m http.server 8080
```

## Как добавить свои блюда
Все варианты лежат в массивах `SNACKS` и объекте `BANK` в начале `app.js`. Просто добавьте новый объект `{ name, desc, hint }` в нужный список — календарь и шторки выбора подхватят его автоматически.
