# 🍽 Меню на день — PWA для набора веса

Простое мобильное веб-приложение (PWA) для выбора еды на день на двоих.
Рацион построен по вашему банку вариантов: завтраки, обеды, ужины и перекусы.

## Возможности
- 🎲 **Конструктор дня** — одним тапом собирает день: завтрак + 2 перекуса + обед + ужин.
- 🔄 **Умная ротация** — не повторяет то, что вы ели в последние 3 дня.
- ❤️ **Нравится** — сохраняйте удачные дни с сердечком.
- 🕘 **История** — все собранные дни хранятся в телефоне (localStorage).
- 📤 **Поделиться** — отправьте меню девушке через любой мессенджер (Web Share API / копирование текста).
- 📖 **Банк вариантов** — полное описание всех блюд с рецептами и лайфхаками.
- 📱 **Ставится на главный экран** как настоящее приложение (Add to Home Screen), работает офлайн.

## Как запустить

### Вариант 1: локальный сервер (для теста и установки на телефон)
```bash
cd food-day-app
python3 -m http.server 8080
```
Откройте `http://localhost:8080` в браузере телефона (в той же Wi-Fi сети —
используйте IP компьютера вместо localhost).

### Вариант 2: GitHub Pages / Netlify / Vercel
Просто залейте папку `food-day-app` на любой хостинг статики — всё заработает.
Для Service Worker и кнопки «Установить» нужен HTTPS (GitHub Pages даёт его бесплатно).

### Установка на телефон
- **iPhone (Safari):** Поделиться → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## Структура
```
food-day-app/
├── index.html            # разметка (3 экрана: День, Банк, История)
├── style.css             # мобильный тёплый дизайн
├── app.js                # банк рецептов, генератор дня, хранение
├── manifest.webmanifest  # PWA-манифест
├── sw.js                 # офлайн-кэш
└── icon.svg              # иконка приложения
```

## Как менять рацион
Все блюда лежат в объекте `BANK` в начале `app.js` — добавляйте новые варианты
в массивы `breakfast`, `lunch`, `dinner`, `snack`, и конструктор начнёт их использовать автоматически.
